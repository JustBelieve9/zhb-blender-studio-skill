# Проверка версии 0.1.0

Среда: Windows, Blender 5.2.2 LTS. Запуск в отдельном процессе с изолированными
каталогами настроек, скриптов и расширений. Производственные сцены не открывались.

Все 11 интеграционных тестов прошли на исходниках и повторно с помощником из
релизного ZIP. Проверки покрывают:

- Отчёт без изменения сцены и без навязанных настроек проекта.
- Подготовку явных параметров, сохранение остальных и отказ при неверном диапазоне.
- Разные текстуры с одинаковым именем файла: уникальные прокси и возврат оригиналов.
- Отказ восстановления при пропавшем оригинале с сохранением recovery-метаданных.
- Collect: ресурсы, дополнительный кэш, сохранность текстового блока и исходного файла.
- Открытие собранной копии после переименования исходной папки.
- Совпадение хешей собранных файлов с манифестом.
- Отказ до копирования при отсутствующих ресурсах.
- Отказ обхода каталогов, существующего назначения и рекурсивного сбора extras.
- Отказ неполной image sequence; сбор непрерывной последовательности и packed image.
- Отказ при linked libraries.
- CLI: сохранение нового `.blend` и отказ перезаписывать существующий.

Дополнительно: официальный `skill-creator/quick_validate.py`, проверка локальных
ссылок/синтаксиса/личных путей, проверка структуры ZIP. Те же интеграционные
проверки выполняются с помощником, извлечённым из релизного ZIP.

Постер PNG просмотрен визуально; SVG сохранён как редактируемый исходник.
Интеграционные тесты не оценивают качество итогового изображения, не проверяют
реальные клиентские проекты и не подтверждают свежесть симуляционных кэшей.
Linux/macOS, UDIM в реальной сцене, HDR-пограничные случаи и поведение сторонних
аддонов в этой версии отдельно не испытаны. Чистка и варианты — агентские
процедуры, а не протестированные универсальные автоматические операции.

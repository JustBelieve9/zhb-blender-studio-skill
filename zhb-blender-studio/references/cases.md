# Production cases

No third-party production cases are bundled. Automated scratch-fixture checks
are documented separately in the repository; they are not customer case studies.

When adding a case, record:

- User request and success criterion.
- Blender version, required providers and non-sensitive reproduction inputs.
- What can change, what must stay intact and where output should be saved.
- Initial report, chosen operation, concrete parameters and reason.
- Before/after files or representative images, measured checks and limitations.
- Whether the user accepted the result and which parts generalize.

Keep private paths, client assets and access credentials out of shared cases.
Add reusable guidance only after reproducing the scenario; keep a project's
specific look, scale or timing as case data rather than a global default.

# ZHB Studio

Помогай пользователю подготавливать и сопровождать Blender-проекты. Отвечай
по-русски, если пользователь не попросил другой язык. Скилл автономен: другие
скиллы, zhb-аддоны, библиотека Core и определённый MCP-сервер не требуются.
Проверенная базовая версия — Blender 5.2.

## Выбери действие

| Запрос | Нужная справка | Готовый помощник |
|---|---|---|
| Проверить сцену, пропавшие ресурсы и тяжёлые данные | [Диагностика](references/diagnostics.md) | `scripts/studio.py report` |
| Задать разрешение, частоту кадров, диапазон или движок | [Подготовка проекта](references/prepare.md) | `scripts/studio.py prepare` |
| Найти и объединить дубли, удалить неиспользуемые данные | [Чистка](references/cleanup.md) | Сценарий для агента; автоматического объединения нет |
| Уменьшить рабочие текстуры или вернуть оригиналы | [Прокси текстур](references/proxies.md) | `scripts/studio.py proxies` / `restore-proxies` |
| Подготовить версии сцены | [Варианты](references/variants.md) | Сценарий для агента; интерфейс не устанавливается |
| Собрать проект с ресурсами | [Сборка проекта](references/collect.md) | `scripts/studio.py collect` |

Способы запуска и аргументы описаны в [справке по запуску](references/execution.md).
Точный состав и ограничения — в [карте возможностей](references/features.md).

## Сохраняй замысел проекта

- Сначала проверь целевую сцену, путь сохранённого файла и доступную версию
  Blender. Не навязывай разрешение, объектив, длительность, лук или движок.
- Диагностика ничего не меняет. Выполняй запрошенное действие; сам отчёт не даёт
  разрешения на чистку. Указывай область: одна сцена или весь файл.
- Перед изменением общих данных выясни, кто их использует. До массовой чистки,
  создания драйверов или замены настроек сохрани восстанавливаемую копию.
  Сохраняй в выбранное пользователем место; исходник по умолчанию не перезаписывай.
- Предпочитай API данных. Проверяй фактические свойства и перечисления RNA,
  а не копируй устаревшие примеры. Ноды ищи по типу или идентификатору,
  а не по переведённым названиям интерфейса.
- При анализе вычисленной геометрии освобождай временные меши в `finally`.
  После проверки восстанавливай кадр, выделение и временные изменения состояния.
- Не удаляй текстовые блоки Text при чистке. Похожих имён, превью или округлённых
  значений недостаточно для объединения ресурсов. Замена текстур должна быть обратимой.
- Сборку запускай отдельным фоновым процессом на сохранённом проекте. Помощник
  отказывается работать с внешними связанными библиотеками и отсутствующими
  ресурсами; не обходи этот отказ молча. Неизвестные кэши требуют явной описи.
- Если вычисление сцены требует аддонов, используй существующий профиль
  пользователя. Не устанавливай, не включай, не удаляй и не перенастраивай
  аддоны ради запуска скилла.

## Проверь изменения

Сравни запрошенные свойства, количество затронутых данных и полученные файлы.
После визуальных изменений просмотри показательные кадры; если визуальной
проверки не было, прямо укажи это. Собранную копию открой повторно и проверь пути.
Если нужна полная независимость, проверь её при недоступной исходной папке:
открытие при доступных оригиналах само по себе не доказывает переносимость.

Сообщи путь результата, конкретные изменения, выполненные проверки и оставшиеся
внешние зависимости. Успешный выход процесса не доказывает одинаковый вид сцены
или свежесть симуляции. Неизвестные форматы кэша отмечай как непроверенные.

## Дополняй по реальным кейсам

Когда пользователь передаст рабочий пример, используй [карточку кейса](references/cases.md).
До обобщения настроек зафиксируй воспроизводимые входные данные и ожидаемый
результат. Предпочтения одного проекта не становятся общими настройками.
